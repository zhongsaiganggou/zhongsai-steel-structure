## 模板一：建筑用途/产品页模板

**适用页面**：工业厂房、物流仓库、矿业设施、商业建筑、农业棚舍等

### URL结构
- 中文：`/zh/steel-[用途].html`
- 英文：`/en/steel-[用途].html`

### 页面结构

#### 1. 页面标题区（Page Hero）
- H1：[建筑用途]钢结构解决方案
- 副文案：直接回答"这是什么、适合谁、中赛提供什么"
- CTA按钮：获取方案报价 / 查看相关案例
- 背景图：真实工厂或项目图片

#### 2. 页面直接答案（100-150字）
- 直接回答：什么是[建筑用途]钢结构
- 适用场景
- 中赛的核心价值

#### 3. 应用场景（Applications）
- 3-6个具体应用场景
- 每个场景配简短说明
- 使用真实图片或图标

#### 4. 关键设计考虑（Key Design Considerations）
- 跨度、高度、吊车、设备荷载
- 通风、采光、屋面墙面系统
- 防腐、未来扩展
- 以列表或表格形式呈现

#### 5. 参数与规格表（Spec Table）
```
| 参数 | 标准范围 | 可选范围 |
|------|----------|----------|
| 单跨跨度 | 18-36m | 12-60m |
| 檐口高度 | 6-15m | 4-30m |
| 吊车吨位 | 5-50吨 | 无-100吨 |
| 主结构钢材 | Q355B | Q235B/ASTM A572 |
| 围护系统 | 压型板/夹芯板 | 定制 |
| 表面处理 | 抛丸Sa2.5+环氧富锌+聚氨酯 | 热镀锌 |
```

#### 6. 选择逻辑（Selection Guide）
- 如何根据用途选择结构形式
- 如何确定跨度和高度
- 吊车需求如何影响设计
- 气候和环境对防腐的要求

#### 7. 设计与制造流程（Process）
```
需求参数 → 初步方案 → 结构设计 → 深化确认 → 生产质检 → 包装出口 → 安装指导
```
- 每一步配简短说明
- 强调中赛在每一步的产出

#### 8. 中赛供应范围（Scope of Supply）
- 主结构：钢柱、钢梁、吊车梁、桁架
- 次结构：檩条、支撑、拉条
- 围护系统：屋面板、墙面板、夹芯板
- 配套：螺栓、门窗、采光板、通风器
- 服务：设计、深化、制造、出口、安装指导

#### 9. 服务范围与业务边界（Scope Box）
- 双栏对比：我们提供什么 / 我们不提供什么

#### 10. 相关案例（Related Projects）
- 2-3个相关项目案例卡片
- 每个案例：国家、建筑类型、简短描述
- 链接到项目详情页

#### 11. 相关产品/构件（Related Products）
- 3-4个相关产品或构件
- 链接到对应页面

#### 12. FAQ（至少6个）
- 真实采购者会问的问题
- 例如：价格、交期、最小起订量、设计标准、安装、出口等

#### 13. 询价表单（Quote Form）
- 双入口：有图纸 / 无图纸
- 字段：姓名、国家、微信、WhatsApp、邮箱（可选）、项目类型、长宽高、是否有吊车、项目说明
- 广告参数隐藏字段

## 模板二：构件与材料页模板

**适用页面**：钢柱、钢梁、桁架、檩条、夹芯板、螺栓等

### URL结构
- 中文：`/zh/products/materials/[构件名].html`
- 英文：`/en/products/materials/[component-name].html`

### 页面结构

#### 1. 页面标题区
- H1：[构件名称] | 按图纸定制加工
- 副文案：直接回答这是什么、用在哪里、中赛如何制造

#### 2. 页面直接答案
- 什么是[构件名称]
- 在钢结构中的作用
- 中赛的制造能力

#### 3. 构件类型与规格（Types & Specs）
- 按类型分类（如：焊接H型钢、热轧H型钢、箱型柱）
- 每种类型的规格范围
- 参数表格

#### 4. 技术参数表（Technical Spec Table）
```
| 参数 | 标准范围 | 可选范围 |
|------|----------|----------|
| 截面高度 | 200-2000mm | 定制 |
| 翼缘宽度 | 100-800mm | 定制 |
| 腹板厚度 | 6-30mm | 定制 |
| 材质 | Q355B | Q235B/ASTM A572 |
| 长度 | 6-15m | 定制拼接 |
| 表面处理 | 抛丸+涂装 | 热镀锌 |
```

#### 5. 制造流程（Fabrication Process）
```
图纸确认 → 材料采购 → 下料切割 → 组立 → 焊接 → 矫正 → 钻孔 → 表面处理 → 检验 → 编号包装
```
- 每一步配简短说明
- 使用真实工厂图片

#### 6. 质量控制（Quality Control）
- 材料检验（材质单、复检）
- 尺寸检验（下料、组立、成品）
- 焊接检验（外观、无损检测）
- 表面处理检验（除锈等级、漆膜厚度）
- 成品检验（编号、包装）

#### 7. 应用场景（Applications）
- 该构件用在哪些建筑类型
- 链接到相关建筑用途页面

#### 8. 选择逻辑（Selection Guide）
- 如何根据荷载选择截面
- 如何选择材质
- 表面处理选择建议

#### 9. 包装与出口（Packing & Export）
- 构件编号方式
- 包装方式（捆绑、装箱、支架）
- 装柜考虑（长构件、重构件）
- 出口单证

#### 10. 服务范围与业务边界

#### 11. 相关构件（Related Components）
- 3-4个相关构件
- 链接到对应页面

#### 12. FAQ（至少6个）
- 材质、规格、交期、最小起订量、包装、出口等

#### 13. 询价表单

## 模板四：项目案例模板

**适用页面**：具体项目案例详情页

### URL结构
- 中文：`/zh/projects/[国家]-[项目类型].html`
- 英文：`/en/projects/[country]-[project-type].html`

### 重要：事实安全
- 只使用已确认的项目事实（A类）
- 未确认的数据不展示（面积、吨位、年份、客户、货柜数等）
- 不编造项目数据、客户评价、技术难点
- 图片必须是该项目真实图片，不使用其他项目图片冒充
- 如事实不足，降级为轻量展示页

### 页面结构

#### 1. 页面标题区
- H1：[项目类型]项目 in [国家]
- 项目Fact Bar（只显示已确认信息）：
  - 国家
  - 行业
  - 建筑类型
  - 中赛服务范围
  - 项目阶段
- 没有确认的数据不显示（不显示"N/A"或"Unknown"）

#### 2. 项目概述（Project Overview）
- 100-180字
- 回答：这是什么项目、在哪里、什么建筑类型、中赛实际供应了什么
- 不使用"中赛是领先的..."开头

#### 3. 项目需求（Project Requirements）
- 只写实际确认的需求
- 如：大跨度、吊车系统、重设备荷载、防腐要求、出口包装要求
- 如没有具体挑战数据，使用"项目需求"而非"项目挑战"

#### 4. 中赛服务范围（ZhongSai Scope）
- 明确中赛在这个项目做了什么
- 从真实适用项选择：
  - 工程协调、设计深化、加工图、钢结构制造、钢构件、次结构、屋面墙面系统、材料供应、表面处理、检验、包装、装柜、出口单证支持、物流协调、安装图、海外技术指导
- 没有证据的项目能力不勾选
- 禁止：当地施工、当地总包、EPC、交钥匙当地安装

#### 5. 工程与制造（Engineering & Fabrication）
- 如果有具体项目资料，说明实际工程/加工要求
- 如果没有，只展示可确认的项目加工内容
- 不把公司通用生产能力冒充本项目发生过的事情

#### 6. 工厂生产（Factory Production）
- 优先使用当前项目真实制造照片
- 如使用通用工厂照片，明确标注"中赛制造能力"而非"项目生产照片"

#### 7. 包装与出口（Packing & Export）
- 只有项目确认涉及出口才加入
- 使用实际确认内容：构件编号、包装、装柜、出货准备
- 不知道的信息（货柜数、港口、船期、贸易条款）不写

#### 8. 项目图集（Project Gallery）
- 使用真实图
- 每张图片ALT描述实际画面
- 禁止关键词堆砌的ALT

#### 9. 相关能力（Related Capabilities）
- 根据项目类型链接商业页
- 例如工厂项目：链接工厂建筑、钢结构制造、出口页面
- 不每个案例一模一样

#### 10. 相关市场（Related Market）
- 如果已有相应国家页，链接国家页

#### 11. FAQ（3-5个，与当前项目有关）
- 例如：中赛为这个项目供应了什么？钢结构是在中国加工的吗？构件如何准备出口？
- 如果答案没有证据，不创建

#### 12. CTA
- Planning a Similar Project?
- Have Drawings / BOQ? → Send Your Drawings / BOQ
- No Drawings Yet? → Send Your Project Requirements
- URL：`/en/contact?source=project-[slug]`

### 项目案例结构化数据

## 通用组件规范

### 按钮系统
- 主按钮（btn-primary）：施工橙背景，白色文字
- 次按钮（btn-secondary）：深墨蓝背景，白色文字
- 浅色按钮（btn-light）：白色背景，深墨蓝文字
- 小按钮（btn-sm）：用于卡片内CTA

### 卡片系统
- 产品卡片（product-card）：图片+标题+描述+标签
- 构件卡片（component-card）：图片+名称+规格
- 案例卡片（case-card）：图片+国家+建筑类型
- 客户入口卡片（customer-card）：图标+标题+描述+列表+CTA

### 参数表（spec-table）
- 深墨蓝表头
- 斑马纹行
- 移动端横向滚动

### FAQ折叠
- 问题加粗
- 点击展开/收起
- 加号/减号图标

### 询价表单
- 双入口切换（有图纸/无图纸）
- 微信必填，邮箱可选
- 长宽高字段（无图纸时显示）
- 广告参数隐藏字段（9个）
- 提交状态反馈

### WhatsApp浮动按钮
- 右下角固定
- 施工橙背景
- 悬停显示提示

## 视觉规范

### 颜色变量
```css
--ink: #0b1720;        /* 深墨蓝 */
--steel: #657178;      /* 钢材灰 */
--paper: #f2f1ec;      /* 纸张色 */
--orange: #ff5a1f;     /* 施工橙 */
--lime: #d7ff57;        /* 安全荧光黄 */
--line: #cfd3d1;        /* 边框线 */
```

### 设计原则
- 工业工程风格，方正硬朗
- 少圆角（4px以内）
- 少渐变（尽量纯色）
- 禁止emoji图标（使用SVG或文字）
- 工程图纸网格元素作为背景装饰
- 强标题，清晰数字和参数
- 大型真实工厂图片

### 图片规范
- 使用真实公司素材（航拍、车间、构件、装柜）
- 不使用低质量AI假项目图
- 不使用无关Stock Photos
- 不使用看起来像小作坊的图片
- LOGO只能使用现有官方中赛LOGO，不得AI生成
